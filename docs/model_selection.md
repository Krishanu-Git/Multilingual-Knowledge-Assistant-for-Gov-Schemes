# Local model selection and limits

**LLM candidate:** Qwen3-4B through local Ollama (`qwen3:4b` default). The adapter sends only retrieved evidence and the question to the local runtime, with low temperature. It does not auto-download weights. The [model card currently lists Apache-2.0](https://huggingface.co/Qwen/Qwen3-4B); confirm the exact checkpoint/runtime terms before deployment. If unavailable, the application shows cited excerpts and a setup warning; it never switches to a paid endpoint. No English/Bengali/Hindi quality benchmark has been run here.

**Embeddings:** `intfloat/multilingual-e5-large`, optional Sentence Transformers, with `query: ` and `passage: ` prefixes and normalized vectors. The [current card lists MIT and 94 languages](https://huggingface.co/intfloat/multilingual-e5-large). It is configured off by default, loads only when enabled, and the runtime cache avoids repeating model loading. Query-time document encoding is currently performed from stored text; there is no persisted FAISS vector index or unchanged-document embedding reuse yet. This is a known gap; BM25 continues to work. The model is large (roughly 2.2 GB weights depending on format) and can require several GB of RAM; validate on target hardware.

**Speech:** optional faster-whisper running locally (`large-v3-turbo` default). The [Whisper model card lists MIT](https://huggingface.co/openai/whisper-large-v3-turbo) and 99 languages, while cautioning that performance varies and recommends task-specific evaluation. IndicConformer was not integrated because no genuine audio benchmark was available in this environment. Whisper decoding is provisional, not a measured best model; CPU int8 can be slow and memory intensive. Audio is not saved or logged. TTS and IndicTrans2 translation are not integrated.

Optional model install: `pip install -e '.[models]'`. Set `GSA_EMBEDDINGS_ENABLED=true` only after installing weights explicitly. Set `GSA_STT_PROVIDER=faster-whisper` and `GSA_STT_MODEL=large-v3-turbo` for local transcription; first transcription may fetch model weights, so install/pre-cache them before offline use. Weight sizes/hardware vary by quantization and runtime; no fixed performance is claimed.
