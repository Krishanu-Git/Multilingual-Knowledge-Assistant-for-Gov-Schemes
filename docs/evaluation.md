# Evaluation

The 10,000 Q&A pairs / 10 language goal in the supplied PPT is a target, not an available benchmark. `data/evaluation/qa.json` is empty until evaluators add manually verified items with `question`, `expected_scheme_ids`, `query_language`, supporting document IDs/passages, reference facts, expected answer language, expected eligibility and abstention flag, and verification notes. `python scripts/evaluate.py --dataset data/evaluation/qa.json --k 5` reports Recall@k, Precision@k, MRR and nDCG@k for the currently configured retriever. Empty data is reported as no evaluation, never as a fabricated score.

Answer factuality, citation support, unsupported claims, answer completeness, abstention and language consistency need annotated human evaluation. Eligibility should be evaluated condition-by-condition, including missing and conflicting information. Speech WER requires real, licensed English/Bengali/Hindi audio and manually reviewed transcripts; no audio fixtures or WER scores are supplied. Dense-vs-BM25 and reranking comparisons require the verified set and are not claimed yet. Evaluation records can be exported to JSON for MLflow or another local experiment tracker; integration is not included.
